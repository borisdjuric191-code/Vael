# Nachträge für die Lore-Bibel (gesammelt, wird beim nächsten Doc-Durchgang übertragen)

- **Floromant (Reiter Floromant):** Die Floromantin trägt kein Waage-Zeichen auf dem Körper. Ihr Nid zeigt sich an den Schattenformen der Pflanzen und im HUD. Später soll der Zustand Licht, Zwielicht oder Schatten über Flügel oder Kleidung sichtbar werden (Entscheidung Boris 8.11.).
